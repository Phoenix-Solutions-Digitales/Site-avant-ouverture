# Photos du blog — à ajouter par Yannick

Ce dossier est vide pour l'instant. Dépose ici tes photos Pexels (libres de
droits) en respectant exactement ces noms de fichiers pour qu'elles
s'affichent automatiquement, sans toucher au code :

| Fichier attendu              | Utilisé sur                                   |
|-------------------------------|-----------------------------------------------|
| `article-1-hero.jpg`          | Image d'en-tête de l'article 1 (site vitrine) |
| `article-1-vignette.jpg`      | Vignette de l'article 1 sur la page liste      |
| `article-2-hero.jpg`          | Image d'en-tête de l'article 2 (multimédia)   |
| `article-2-vignette.jpg`      | Vignette de l'article 2 sur la page liste      |
| `article-3-hero.jpg`          | Image d'en-tête de l'article 3 (identité)     |
| `article-3-vignette.jpg`      | Vignette de l'article 3 sur la page liste      |

Format conseillé : JPG, ~1600×900 px pour les "hero", ~800×450 px pour les
vignettes (poids < 300 Ko chacune pour ne pas ralentir le site).

Tant qu'un fichier est absent, la page affiche automatiquement un dégradé
bordeaux/or avec le nom du pôle à la place — rien ne casse visuellement.
